# Vertical Classes ERP

ERP Management System for Vertical Classes Coaching Institute.

## User Roles

- Admin
- Teacher
- Student

## Tech Stack

### Mobile
- React Native
- Expo

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Mongoose

## Core Modules

- Authentication
- Teacher Management
- Student Management
- Batch Management
- Teacher Attendance
- Student Attendance
- Lecture Logs
- Fees & Payments
- Fee Receipts
- Reports
